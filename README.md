# 知合 A210 资源总汇 · Zhihe A210 resource index

A single page collecting everything publicly findable for the **Zhihe Computing A210** (Archimedes A210) — SODIMM compute module on V1 / V2 / V3 carriers, plus the compute-stick form factor: official documentation and datasheet, direct official image downloads, per-board flashing guides, open-source carrier design files, upstream kernel and firmware work, GitHub and Gitee projects, tutorials, and the few videos that actually show the board.

知合计算 A210（阿基米德 A210）的资源总汇，覆盖 SODIMM 核心板 + V1 / V2 / V3 底板与算力棒形态：官方文档与规格书、**可直接下载的官方镜像**、按板型分的烧录指南、开源底板设计文件、上游内核与固件进展、GitHub 与 Gitee 项目、教程，以及少数真的拍了这块板子的视频。
